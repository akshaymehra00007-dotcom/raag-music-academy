# Raag Music Academy

A responsive website for Raag Music Academy in Surat, with original academy photos, course tabs, playable musical notes, a photo gallery, Google Maps and a compact WhatsApp enquiry form.

## Preview

Serve the `dist` folder using any static web server. The entry point is `dist/index.html`.

## Contact

Enquiries use the academy phone number +91 85050 81961. WhatsApp enquiries open a draft for the visitor to review and send.
